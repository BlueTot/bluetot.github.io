You found an easter egg on my website!

What you’re seeing

On the homepage, clicking the title triggers a short animation where each character “glitches” through ASCII symbols before settling on nok hang lo. It’s not just random noise — the randomness is weighted by probabilities generated from a Qiskit Grover’s algorithm simulation.

  • Input: the target string (nok hang lo)
  • Data: assets/probs.json (a list of probabilities over Grover iterations)
  • Output: a flicker that converges from “chaos” → “correct letters”

How the flicker works (in plain English)

  • The animation runs in iterations (you used 0 → 12).
  • For each iteration, we have a number highProb (from probs.json). Think of it as “confidence” that the output should be the correct character.
  • For each character position in the word, we randomly pick an ASCII character:
    • with probability highProb, pick the correct target character
    • with remaining probability, pick a uniform random ASCII char (noise)
  • As highProb increases over iterations, the output “locks in”.

So the “quantum” part isn’t that the browser runs quantum code — it’s that the probability schedule was produced by a Grover simulation, then used to weight randomness in JavaScript.

Where the probabilities come from (Grover’s algorithm)

In your Python/Qiskit script, you simulate Grover’s search on an 8-qubit circuit. Each Grover iteration increases amplitude (and therefore probability) of “marked” states.

  • Oracle: marks the target bit-pattern (you build anti-controls based on the character’s bits)
  • Diffusion: amplitude amplification step (reflect about average)
  • Statevector simulator: you collect probabilities each iteration
  • Export: store the largest probability after each iteration into assets/probs.json

You then reuse that array in the frontend as highProb values over time.

Generating a circuit diagram image

Yes — Qiskit can render circuits to images. Two common options:

Option A: save to PNG (recommended)

Add this to your Python script after building qc:

from qiskit.visualization import circuit_drawer

# Save the circuit diagram as a PNG
circuit_drawer(qc, output="mpl", filename="assets/grover_circuit.png", fold=-1)

Option B: save to SVG (nice for web)

SVG scales perfectly on your site:

from qiskit.visualization import circuit_drawer

circuit_drawer(qc, output="svg", filename="assets/grover_circuit.svg", fold=-1)

If you use output="mpl", you may need matplotlib installed. For SVG output, it’s usually simpler and web-friendly.
